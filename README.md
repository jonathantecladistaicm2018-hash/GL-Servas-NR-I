# GL Servas NR I — Projeto Android v1.0

Aplicativo Android inicial para o GL Servas NR I.

## Identidade
- Nome: GL SERVAS NR I
- Visual: rosa, rosa musical e notas musicais
- Sem a frase “Louvor • Adoração • Comunhão”
- Sem escala de músicos

## Módulos da versão inicial
- Áudios
- Hinos Cifrados
- Hinos sem Cifras
- Experiências
- Ensaios
- Avisos
- Pesquisa
- Favoritos
- Administração

## Como gerar o APK
Abra a pasta no Android Studio com um computador conectado à internet. O Android Studio poderá baixar o Android Gradle Plugin e o SDK necessários. Depois use:
Build > Generate App Bundles or APKs > Generate APKs.

O APK de debug normalmente será criado em:
app/build/outputs/apk/debug/app-debug.apk

## Observação sobre o símbolo da ICM
O projeto atual usa uma arte provisória própria para o ícone. Para usar o símbolo oficial da ICM, substitua o arquivo de ícone por uma imagem oficial que você tenha autorização para utilizar.
